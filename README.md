# Seed Morphology Analyzer Version 2.4.0

Bread Research Analyzerと同じMySQLデータベース・Python仮想環境を共有する、種子形態解析モジュールです。Bread既存テーブルは変更しません。

## 主な機能

- OpenCVによる粒数カウント
- Distance Transform + Watershedによる接触粒分離
- Otsu／手動二値化、CLAHE、Gaussian Blur、Morphology
- 個体別形態計測：面積、周囲長、長径、短径、長短径比、円形度、充実度、Extent、凸包面積、等価直径、重心、方向
- 全体統計：平均、標準偏差、最小、最大、変動係数
- px/mm設定によるmm・mm²換算
- 解析途中画像のサーバー保存
- 個体別CSV、全体サマリーCSV
- 履歴・詳細表示・ライブプレビュー
- 履歴の元画像を使った条件変更・再解析（新しい履歴として保存）
- 元画像・結果画像のダウンロード
- スマートフォンのカメラ・写真ライブラリ・ファイル選択
- JPEG・PNG・WebPアップロード
- 画像上をドラッグして解析範囲（ROI）を指定
- 解析結果上でカウント追加・削除
- 自動検出値を保持した手動補正履歴

## Version 2.0.1の使い方

- 管理者モードの履歴一覧または詳細画面で「再解析」を押すと、保存済み元画像と当時の条件を読み込みます。
- 条件を変更して保存すると、元の記録を残したまま新しい履歴を作成します。
- 「元画像DL」「結果DL」で各画像を端末へ保存できます。
- 新規解析画面の画像選択では、スマートフォンのカメラ、写真ライブラリ、ファイルを利用できます。
- HEIC/HEIFはOpenCV 4.5.5で直接扱えないため、スマートフォン側でJPEG・PNG・WebPとして選択してください。

## Version 2.1の追加機能

- 画像選択後に「解析範囲（ROI）を指定」を押し、画像上をドラッグすると、その矩形内だけを解析します。
- 「画像全体に戻す」でROIを解除できます。ROIは比率で保存され、端末の表示サイズに依存しません。
- 履歴または詳細画面の「手動カウント補正」から、見落とし位置の追加と誤検出粒の削除ができます。
- 補正は自動解析オブジェクトを消さず、日時・自動粒数・補正後粒数・メモを履歴として保存します。

Version 2.0.1から更新する場合は、ファイルを上書きする前後に `database/migration_v2_0_1_to_v2_1_0.sql` を1回実行してください。既存の `config.php` と `uploads/` は保持します。

## Version 2.2の精度改善

- 大きなGaussian背景推定と除算による照明ムラ・影補正
- Otsu／手動に加えてAdaptive Thresholdを追加
- 連結領域ごとのDistance Transformと局所ピークによるWatershedマーカー生成
- 大粒が基準となって小粒のマーカーが消える従来方式を改善
- 正常粒は緑、形状条件に注意が必要な粒は黄、面積外の候補は赤で表示
- 形状条件から外れた粒を即時削除せず「要確認」としてカウントし、検出漏れを抑制

Version 2.1から更新する場合は `database/migration_v2_1_to_v2_2.sql` を1回実行してください。

### Version 2.2.1修正

局所Watershedのデバッグ用Distance Transform画像を生成するときに、旧変数名が残っていたため発生した `name 'max_distance' is not defined` を修正しました。Version 2.2.0からの更新ではDB変更はありません。

## Version 2.3の画像拡大表示

- 解析結果画像のタップ、または「解析画像を拡大表示」で全画面ビューアを開きます。
- ＋／－による0.5～8倍の拡大縮小、リセット、ドラッグ移動、マウスホイール拡大に対応します。
- スマートフォンでは拡大後の画像を指で移動できます。
- Version 2.2.1からの更新にDB変更はありません。

## Version 2.4の操作改善

- 手動調整画面の各スライダーに数値入力欄を追加しました。
- スライダー操作と数値入力は双方向に同期し、どちらからでもライブプレビューできます。
- 履歴の「再解析」は別画面を使わず、新規解析と同じ画面へ元画像・試料名・メモ・当時の条件を読み込みます。
- 再解析画面でもROI、Adaptive Threshold、背景補正、ライブプレビュー、既定値保存を利用できます。
- 必要な場合は別画像を選択して差し替えることもできます。
- Version 2.3からの更新にDB変更はありません。

## Version 1.4から更新

1. フォルダとDBをバックアップします。
2. `database/migration_seed_morphology_v2_0.sql` をBreadと同じDBで1回実行します。
3. 既存の `seedcount/config.php` と `seedcount/uploads/` は保持します。
4. 新しいプログラムファイルを配置します。
5. `uploads/stages/` にPHP書込み権限を付与します。
6. `diagnose.php` で確認します。

新規設置の場合は、旧版用マイグレーションではなく `database/install_seed_morphology_v2_complete.sql` を1回実行してください。

## 注意

- `migration_seed_morphology_v2_0.sql` は一度だけ実行するALTER文を含みます。
- 完全に重なった種子は通常の2D画像だけでは正確に分離できません。
- mm換算には、同じ撮影面上のスケールから `pixels_per_mm` を求める必要があります。
- 判定精度は背景、照明、撮影距離、品種に依存します。同一条件で標準試料を使ってパラメータを調整してください。
